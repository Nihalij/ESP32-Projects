# ESP32 Basic Wi-Fi Connection

A basic ESP32 project that connects the ESP32 to a Wi-Fi network and displays its IP address on the Serial Monitor.

## Hardware
- ESP32

## Software
- Arduino IDE / Wokwi

## Library
- WiFi.h

## How It Works
1. ESP32 starts the Wi-Fi connection.
2. It waits until the connection is established.
3. Once connected, it prints the ESP32's IP address.

## Example Output

```text
Connecting to WiFi.....
WiFi Connected!
IP Address: 10.10.0.2
